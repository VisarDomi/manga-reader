Definition:
- "may" means do it if its there

Reader:
- On scrollend + 100 ms, each visible chapter may append its immediate newer chapter exactly once.
- On scrollend + 100 ms, save the current loaded image in the page URL + local/server tracking
- Tracking: update the local frontier. Server tracking happens once per chapter when supported
- Opening or refreshing a reader URL, the app may restore to the corresponding image

Home:
- show all entries (eventually)
- the single local resume position for a provider and series always wins when present
- server resume is used only when there is no local resume position
- clicking on cover resumes
- clicking on chapters resumes the chapter (unread - start_page, read - end_page, partial - saved_page).

Special feature:
- bfcache - going back (swipe back) from reader to home loads home from cache
- image self register to retry in case they fail to load
- if resume/initial is unavailable, location.href to series page for the user to verify its actually like that
- if no provider height, use 1000px height which will then get replaced by actual heights when data comes in
